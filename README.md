# Moments & Memories Studio

Elegant Next.js website for **mm.studio.kwt** — Wedding Photography & Videography studio based in Kuwait.

## Features

- **Home** — Hero, featured couples (D&J, F&M, R&M, D&K), services overview, about teaser, CTA
- **Portfolio** — Gallery grid of wedding & engagement stories
- **Services** — Photography, Videography, Album Design + additional offerings
- **About** — Studio philosophy and international photographers positioning
- **Contact** — WhatsApp & Instagram CTAs with booking guidance

## Design

- Serif headings (Playfair Display) + clean sans body (Inter)
- Warm cream / charcoal / accent palette suited to wedding photography
- Fully responsive, mobile-first navigation
- Smooth scroll, elegant hover states

## Getting Started

```bash
cd mm-studio
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build for Production

```bash
npm run build
npm start
```
